# TRIPAN V10 — Transport Phase 1

1. In Supabase SQL Editor, run `TRIPAN_TRANSPORT_SUPABASE.sql`.
2. Start the project with `npm run dev`.
3. Open Services → Transport.
4. Test Ahmedabad, Goa, Hyderabad, Mumbai, Delhi and Visakhapatnam.
5. Transport fares are approximate planning ranges, not live quotes.
6. Images are generic public image URLs/fallbacks; they are not claimed to be photos of a specific operator.
7. Existing Home, Explore, Plan My Trip, Hotels and Restaurants logic was not intentionally changed except the shared `showService()` routing needed to add Transport.
